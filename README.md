# 永森油服学习小程序

2.0 使用微信原生小程序直接接入腾讯云 CloudBase。员工学习与培训管理都在同一个小程序内，业务不再依赖 Java 服务、Web 管理后台、云托管网关或 MySQL，也不保留旧接口与回退通道。

- 小程序：微信身份、角色入口、员工核验、教材上传、任务发布、视频/PDF 学习、本人确认、培训记录、进度监控与 CSV 导出。
- 云函数：`ys-training` 处理鉴权与业务事务，`ys-jobs` 处理发布分配和通知，`ys-materials` 校验视频与渲染 PDF。
- 云数据库：`ys_` 前缀的文档集合；客户端按权限直接查询与监听，所有业务写操作由云函数执行。
- 云存储：私有文件；管理员获得指定对象上传凭据，学员通过任务权限校验取得短期媒体地址。

## 角色规则

微信公众平台的**管理员和全部项目成员**均拥有业务 `ADMIN` 权限；体验成员和其他用户默认为 `USER`。一个账号同时具有两种成员来源时，移除其中一种不会撤销剩余来源带来的权限。

微信小程序运行时不直接提供公众平台成员名单。成员通过真实微信身份生成 10 分钟有效的核验码，已有管理员在小程序「账号权限」中对照公众平台名单核验、设置来源，并记录说明。普通用户不能自助提权。首位管理员通过受控部署流程，使用已经核验的真实微信 OpenID 初始化；系统没有“首个登录者自动成为管理员”的入口。

## 开发与部署

```sh
npm run setup
npm test
npm run build
```

微信开发者工具可直接导入 `miniprogram/`。该目录默认连接上述真实云环境，任何管理操作都会写入真实环境，请使用明确标识的验收任务。

部署云资源前，在操作者的终端环境设置 `TENCENTCLOUD_SECRETID`、`TENCENTCLOUD_SECRETKEY` 和 `CLOUDBASE_ENV_ID`，再运行 `npm run deploy:cloud`。部署程序创建集合、索引、权限规则、三个云函数及分钟调度，并回读校验运行代码。运行时使用云平台临时身份，不把部署密钥写入函数或小程序。微信云调用权限的注册步骤见架构文档。

`npm run build` 输出小程序到 `miniprogram/release/v2-*`，合法域名校验保持开启。用微信官方 CLI 上传指定构建目录；上传开发版本、设置体验版、提交审核和正式发布是不同步骤，具体完成状态以验收记录为准。

## 测试与运行说明

- `npm test`：云端领域与权限测试、小程序请求协议、学习采集和构建测试。
- `E2E_ASSIGNMENT_ID=<新任务编号> npm run test:native --prefix miniprogram`：连接官方开发者工具自动化端口，真实播放视频、阅读 PDF、点击本人确认并核对记录。账号需事先完成绑定，该任务必须尚未完成。
- 订阅消息需微信实际授权；`ACCEPTED` 只表示微信接口受理，不能当作手机送达或阅读证明。
- 学习进度验证覆盖播放区间、可见范围与有效时长，不能证明持续专注、理解程度或岗位资格。
