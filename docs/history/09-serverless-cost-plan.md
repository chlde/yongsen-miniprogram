# 按量部署方案与费用预算

> 历史选型与预算记录（2026-10-17）。下文“尚未部署”等状态属于当时阶段，价格估算不作为当前报价或费用承诺。后续已经采用并部署 CloudBase 网关与独立 SCF 的组合，参见 [13 当前架构](13-project-architecture-and-deployment.md) 和 [12 云部署记录](12-cloud-deployment-status.md)。

更新日期：2026-10-17。根据“数据库也使用云服务、尽量按调用次数收费”的要求，已完成 SCF 入口、COS 直传与处理、事件作业、按次释放 JDBC 连接和小程序 HTTPS 生产构建的代码适配。当前部署资产和参数以 [SCF 部署说明](../deployment/serverless/README.md) 为准；上一层 `deployment/` 中的常驻容器和 CFS 保留作旧方案。镜像构建、云端发布与真实微信验收仍待完成，代码适配完成不等于已经上线。

## 1. 选型

采用腾讯云 **SCF 云函数 + TDSQL-C Serverless MySQL 8.0 + 私有 COS 对象存储**，继续使用现有微信小程序与 Java 业务代码。资源优先同地域部署。SCF 是独立腾讯云产品，不是截图中微信云托管的框架模板；需要对应腾讯云账号具备资源权限，不能仅凭已登录微信云托管就认定能够创建。

| 能力 | 目标服务 | 计费与设置 |
| --- | --- | --- |
| 登录、任务、学习记录、管理后台 API | SCF Web 函数，保留 Java / Spring Boot | 按调用次数、运行资源时间及流量计费；初期不设置预置并发 |
| 人员、任务、学习事件、通知状态 | 独立 TDSQL-C Serverless MySQL 8.0 | 按活跃算力时间与实际存储计费；启用空闲自动暂停，通过内网 JDBC 连接 |
| 视频、原始 PDF、页图 | 私有 COS 标准存储 | 按容量、请求和下载流量计费；客户端取得短期授权后直接访问 |
| 材料处理、任务通知 | SCF 事件桥接函数 + Java 内部 worker | 事件函数等待带独立鉴权的 Java worker 执行完成；持久作业管理重试与租约，不持续轮询 |
| 管理后台页面 | 构建后的静态文件 | 初期可随 Web 函数提供；业务资料仍走 COS |

云函数并非只按次数收费；数据库也不是按 SQL 条数收费。数据库暂停后停止计算收费，存储继续收费。自动暂停要求没有连接和 CPU 使用；当前 `serverless` profile 已关闭轮询，并通过 `DriverManagerDataSource` 在数据库操作或事务结束后物理关闭连接，避免依赖冻结实例中的连接池淘汰线程。实际云库能否按预期暂停仍须上线验证。[SCF 定价](https://cloud.tencent.com/document/product/583/12281)、[数据库自动启停](https://cloud.tencent.com/document/product/1003/115618)。

MySQL 初始按一个读写实例设计，不附加只读实例；选用支持 MySQL 8.0 的 Serverless 形态，具体可用规格、备份能力和账号报价在资源创建前核实。单实例适合初期试运行，不能据此承诺多可用区容灾。[实例形态](https://cloud.tencent.com/document/product/1003/107173)。

## 2. 预算口径

这是价格模型，不是压测结果或账号订单。按中国大陆普通地域公开价格估算，不抵扣新人优惠、赠送额度或资源包。

假设每月：100 名员工，每人观看 1 小时视频，音视频合计平均码率 2 Mbps；教材及页图共 20 GiB；数据库实际占用 5 GiB；API 调用 10 万次，内存与当前部署初始规格保持一致，按 **3072 MB（3 GiB）、每次 200–500 ms** 估算；数据库活跃 100 小时，**包含访问后的等待暂停时间**，平均使用 0.25–1 CCU。月长按 30 天、720 小时计算。执行耗时是假设，不是当前云端实测值。

| 项目 | 计算依据 | 预估月费用 |
| --- | --- | ---: |
| API 云函数 | 10 万次 × 3 GiB × 0.2–0.5 秒 × 0.00011108 元/GB·秒 + 10 × 0.0133 元调用费 | 6.80–16.80 元 |
| MySQL 活跃计算 | 100 小时 × 0.25–1 CCU × 0.342 元/CCU·小时 | 8.55–34.20 元 |
| MySQL 存储 | 5 GiB × 720 小时 × 0.00486 元/GiB·小时 | 17.50 元 |
| 教材存储 | 20 GiB × 0.118 元/GiB·月 | 2.36 元 |
| 视频下载流量 | 100 × 3600 × 2,000,000 ÷ 8 ÷ 1024³ ≈ 83.82 GiB；每 GiB 0.5 元 | 41.91 元 |
| 对象读写请求 | 合计按 10 万次、每万次 0.01 元估算 | 0.10 元 |
| **以上核心资源合计** | 预算按约 80–115 元计 | **77.21–112.86 元** |

云函数单价采用每万次 0.0133 元、每 GB·秒 0.00011108 元。上述 API 项未计入材料处理的 Java worker、等待结果的 Node.js 桥接函数、临时磁盘和 API 网络流量；处理期间两个函数会分别计费，实际时长与冷启动开销需在云端样本运行后补齐。[官方 SCF 价格](https://cloud.tencent.com/document/product/583/12281)。

国内 SCF 已取消强制基础套餐费，函数 URL 本身不另收网关费，不额外采购独立网关。目前已有腾讯云账号但暂无自有域名，先使用函数默认 HTTPS URL 做服务端接口联调；这不代表真实微信合法域名验收已经完成，也不承诺默认域名能直接展示管理后台 HTML。正式入口使用实际 HTTPS 域名，按所选地域及小程序平台要求完成备案、证书和合法域名配置。SCF 当前已支持自定义域名。[取消基础费公告](https://cloud.tencent.com/document/product/583/104909)、[函数 URL 费用](https://cloud.tencent.com/document/product/583/107631)、[默认函数 URL](https://cloud.tencent.com/document/product/583/96099)、[当前自定义域名配置](https://cloud.tencent.cn/document/product/583/110861)。

数据库算力单价为 0.000095 元/CCU·秒，存储采用产品架构 1.0 的一级存储价格 0.00486 元/GB·小时。当前官方价格页明确架构 2.0 尚不支持 Serverless 集群，不能将其较低存储价代入本方案；实际购买按支持 Serverless 的规格与地域核算。本预算没有计入多可用区副本、额外数据库审计或超额备份。[官方数据库价格](https://cloud.tencent.cn/document/product/1003/73002)。

COS 采用标准存储、直接外网下载价格；未同时计入 CDN 回源与 CDN 下行，避免重复或混用不同链路价格。[官方 COS 价格](https://buy.cloud.tencent.com/price/cos)。

**上述人数、观看时长、数据库活跃时间与轻量素材处理假设成立时，试运行仍建议预留 100–150 元/月**。100 元对应较低用量一端；按上表较高用量应以 150 元准备，余量用于少量 PDF 处理、日志、备份、文档访问和 API 流量。余量是预算预留，不是报价或费用上限；大量材料处理、较慢接口和频繁冷启动可能超出。域名、小程序账号认证等独立费用未纳入，镜像仓库等资源如有额外费用，须按实际账号订单补入。

影响费用最大的因素是视频总观看时长及数据库保持活跃的时间：

- 在相同码率下，每增加 100 人小时的观看量，视频下载费约增加 42 元；重复观看、拖动重载和更高码率会增加流量。
- 若数据库 0.25 CCU 连续运行整月，计算加 5 GiB 存储约 79.06 元；1 CCU 连续运行则约 263.74 元。用户零散访问、连接池保活和定时查询都可能使实际活跃时间高于 100 小时。
- 若整月没有业务调用且数据库已成功暂停，按本预算存量仍需约 20 元/月保存教材和数据库，另有实际产生的备份等费用。

建议设置 150 元月预算预警，观察首周用量后调整。预警不是强制费用上限；不通过自动删库、删教材或中断正在进行的学习来控制费用。此项尚未在云账号中配置。

## 3. 已完成的适配与云端验收项

1. **运行入口已实现**：新增 `deployment/serverless/` 的 Java 17 SCF Web 镜像、`scf_bootstrap`、独立生产 profile 和白名单打包工具。服务监听 `0.0.0.0:9000`，缺少生产私密配置拒绝启动，不依赖 CFS。镜像构建、SCF 初始化、冷启动和数据库唤醒尚待实际云端验证。[部署参数](../deployment/serverless/README.md)、[Web 函数开发约束](https://cloud.tencent.com/document/product/583/56124)。
2. **COS 存储已实现**：授权直传绑定大小、类型与私有桶继承 ACL；上传完成后按 ETag 条件复制冻结原件，处理完成后记录散列和页图，签发短期访问 URL。临时目录只作处理缓存。实际 COS 权限、浏览器 CORS、视频 Range/206、签名到期刷新仍须云端和手机验收。
3. **事件任务已实现**：作业先持久化，提交事务后调用 SCF 事件桥接函数；桥接使用独立密钥同步等待内部 worker，租约与幂等控制重复执行，保留管理员恢复入口。`serverless` profile 不启动定时轮询。通知发送结果不明仍保留 UNKNOWN，事件重试不会据此标记送达。实际 SCF 重试、并发和超时恢复仍待验收。
4. **数据库配置已实现**：使用 `DriverManagerDataSource` 物理关闭已使用的 JDBC 连接，不依赖连接池保活或后台淘汰；SQL 自动初始化关闭，生产应独立建空库并执行配套 MySQL schema。实际云库、VPC、安全组、自动暂停与唤醒仍待创建和验证。初期限制函数并发，避免数据库连接数随函数实例无限增长。[SCF 网络配置](https://cloud.tencent.com/document/product/583/123457)。
5. **小程序 HTTPS 构建已实现**：新增 `--transport https --public-https` 生产模式，使用 `wx.request`；保留 `callContainer` 兼容模式和原有 `wx.login`、本系统 token、员工授权链路。拒绝本机或不安全生产地址。默认函数 HTTPS URL 先用于 API 联调，真实小程序合法域名和体验版手机验证尚待完成。
6. **验收分层记录**：本轮完整本地回归已通过，包括后端 168 项、隔离 MySQL 专项 2 项、Web 10 项、小程序逻辑 34 项、部署入口 11 项、浏览器端到端 16 项、MySQL 业务端到端 8 项及备份恢复，版本和证据见 [10 按量适配验收报告](10-serverless-implementation-report.md)。云端还须验证真实登录、学习、记录导出与恢复。订阅消息模板仍待配置，必须取得真实个人微信收件及正确任务跳转证据，才算覆盖通知 MVP。

这些是部署适配，不增加考试、审批、自动催办等产品功能。既有服务端学习判定和审计证据要求继续保留，不以节省调用为由放松完成标准。
