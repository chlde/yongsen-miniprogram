# 企业培训产品改版

更新：2026年10月17日。此次只调整管理端、学员端与原生小程序的产品呈现，并增加工作台与培训主题入口；学习核验、任务固定、微信授权和本人完成流程继续沿用现有 MVP。真实微信接入按用户要求暂缓。

## 产品定位与页面组织

品牌统一为“永森油服 · 企业培训平台”，围绕三个业务方向组织首页：

- **安全生产培训**：安全制度、风险辨识、应急处置。
- **岗位技能培训**：设备操作、标准作业流程、技术规范。
- **员工能力提升**：新人融入、沟通协作、职业素养。

管理员登录后进入培训工作台，首先看到业务重点和培训概况，然后是培训主题、最近培训、工作待办。侧栏依次为培训工作台、培训任务、培训资源、员工管理，通知设置归入平台管理。本地通知测试保留在本地环境的工具入口。

三个主题是创建培训的便捷入口，只预填培训名称和目标。管理员仍需选择真实材料与参训人员，明确提交后才发布；它们不代表已经存在的课程分类、课程库或新增考试能力。

首页不再用“留痕与确认”“可追溯过程”等实现性描述介绍产品。本人确认、发送受理/送达/打开的区别、材料规则等保留在学习详情、通知页和记录页，以支持实际操作和正确理解结果。

- 深海军蓝 `#102b4e` 用于品牌和导航，企业蓝 `#2563eb` 用于主要操作；背景为浅灰 `#f4f6fa`，内容区域以白色为主。
- 采用清晰的侧栏、面包屑、工作区层级；卡片使用细边框、8～10px 圆角，减少装饰性阴影。
- 字体优先系统中文字体；图标为本地 SVG/CSS 线性图形，不依赖外部图片服务。
- 登录页与工作台采用油田作业平台线稿，强调行业背景。手机宽度下改为纵向布局，保留完整功能。
- 原生五页统一企业蓝、白灰底及对应组件层级，保留真实视频/PDF 采集器及所有原有操作。

## 真实数据口径

| 工作台内容 | 当前实现 |
| --- | --- |
| 培训任务 | 全分页读取的任务总数 |
| 已发布培训 | status=ACTIVE；不标为“进行中”，因为全员完成后任务也可保持有效 |
| 在册员工 | status=ACTIVE 的人员数量 |
| 可用培训资源 | status=READY 且 compatibilityChecked=true |
| 员工加入申请 | status=PENDING 的绑定申请 |
| 待发布培训 | status=DRAFT 的任务 |
| 待检查资源 | READY 但尚未通过兼容性检查的材料 |

没有虚构课程数量、能力评分、安全绩效或学习完成率。首次加载失败时显示“—”与错误提示，不把失败当作零。最近培训直接进入对应任务，待办跳转至负责处理该事项的管理页。

同时修正创建培训时的可用资源筛选：必须实际检查通过，不能仅凭“存在检查时间”就允许选择。
