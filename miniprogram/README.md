# 原生小程序

`app.js` 通过 `wx.cloud.init` 初始化永森云环境；`lib/api.js` 使用 `wx.cloud.callFunction` 提交业务命令、使用云数据库 SDK 查询和监听数据。无自有登录令牌、HTTP 业务服务、云托管调用或本地模拟入口。

员工页面位于 `pages/`，管理页面位于 `admin/` 分包。角色由云端返回，管理命令仍逐次核验角色。管理员也可绑定员工身份，参加分配给自己的培训。

## 使用

1. 微信开发者工具导入本目录，使用具备当前 AppID 开发权限的微信账号。
2. 登录后，普通用户填写个人邀请码，管理员在员工管理中核对；管理员可从任务首页进入管理工作台。
3. 上传 PDF 或 H.264 MP4 教材，等待处理完成；选择员工和教材创建草稿，再发布。
4. 员工逐份学习，达到要求后勾选本人确认。管理员在任务详情查看实时进展和通知结果，导出培训记录。

`lib/session-tracker.js` 每秒采样、每 5 秒提交；超过 10 秒没有确认会暂停。页面只展示云端确认的进度。视频使用真实原生播放事件，PDF 使用渲染后的页图与实际可见范围；网络异常、拖动跳跃和离开页面不会直接增加学习时长。

## 验证

```sh
npm ci
npm test
npm run build:production -- --version 2.0.0
E2E_ASSIGNMENT_ID=<分配给当前微信账号的新任务> npm run test:native
```

原生 E2E 使用官方 `miniprogram-automator`，默认连接 `ws://127.0.0.1:9420`，可通过 `NATIVE_WS` 覆盖。不伪造播放事件或完成进度。截图与结果写入忽略的 `artifacts/`。

生产构建输出到 `release/v2-*`，不含测试、依赖目录、私有项目设置或密钥。开发者工具测试不等同于 iOS/Android 真机验收，正式发布和手机通知送达状态见仓库的验收记录。
